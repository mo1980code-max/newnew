# مولّد محتوى الأذكار — `res/raw/athkar.json`

```bash
python3 tools/athkar/build_athkar.py
```

يعيد بناء ملف الأذكار من المصدر، ولا يكتب شيئًا إن فشل أي فحص.

## لماذا مولّد وليس تحريرًا يدويًا للـ JSON
الملف 66 كيلوبايت من نص عربي مشكول. التحرير اليدوي فيه يُخفي الأخطاء (نص مبتور، فاصلة
ناقصة، ترجمة في الحقل الخطأ)، و24 ذكرًا مشترك بين الصباح والمساء — نسخها يدويًا يعني
احتمال اختلافها بين القائمتين. هنا النص المشترك مكتوب **مرة واحدة**.

| الملف | الدور |
|---|---|
| `athkar_shared.py` | الأذكار المشتركة بين الصباح والمساء (24): عربي + ترجمة + نقل حرفي + مرجع + فضل |
| `athkar_lists.py` | ترتيب كل قائمة + الأذكار الخاصة بوقتها (فروق «أصبحنا/أمسينا» وأخواتها) |
| `build_athkar.py` | يبني JSON ويتحقّق ثم يكتب |

## المحتوى (منقول من islambook.com)
| | الصباح | المساء |
|---|---|---|
| المصدر | `/azkar/1` | `/azkar/2` |
| عدد الأذكار | 31 | 30 |
| `id` | 1 … 31 | 101 … 130 |
| مجموع النقرات | 374 | 274 |
| معها سطر «الفضل» | 15 | 15 |

التكرارات: الصباح `1,3,3,3,1,1,3,4,1,7,3,1,1,3,3,3,1,3,1,1,3,10,3,3,3,3,1,1,100,100,100`
والمساء `1,1,3,3,3,1,1,3,4,1,7,3,1,1,3,3,3,1,3,1,1,3,10,3,3,3,3,100,1,100`.

## بنية السجل
```json
{
  "id": 1, "type": "morning", "repeat": 1,
  "arabic_text": "…", "english_text": "…", "transliteration": "…",
  "reference_ar": "[آية الكرسى - البقرة 255]", "reference_en": "[Ayat al-Kursi — Al-Baqarah 255]",
  "virtue_ar": "من قالها حين يصبح أجير من الجن حتى يمسى…", "virtue_en": "Whoever recites it…"
}
```

## الفحوص التي تُفشل البناء
- كل الحقول الثمانية موجودة في كل ذكر.
- `repeat` عدد صحيح ≥ 1.
- `arabic_text` يحوي حروفًا عربية فعلًا، و`english_text`/`transliteration` خاليان منها.
- الفضل والمرجع موجودان في اللغتين معًا أو غائبان معًا (لا نصف ترجمة).
- 31 صباحًا و30 مساءً بالضبط، ولا `id` مكرر.
- لا `<` أو `>` أو `&` أو `"` داخل أي نص (المعاينة تبني البطاقات بـ `innerHTML`).

## إضافة ذكر أو تعديل تكرار
عدّل `athkar_shared.py` أو `athkar_lists.py` ثم شغّل المولّد. إن تغيّر العدد عن 31/30
فحدّث التوقّع في `build_athkar.py` — الرقم مفحوص عن قصد، لأن «العدد» جزء من الطلب الأصلي.
